## My_Go_Pet

Привет. Я Паша. Это мой репозиторий для pet-проектов на Go. Изучаю язык с сентября 2026 как основной для дальнейшей работы. Начинал с языка С для школы 21 от Сбера, студентом которой и являюсь.

## Что внутри

Папки с проектами, каждая — свой модуль (`go.mod`).

| Папка | Тема |
|-------|------|
| `uniqueWords` | Программа читает данные из терминала или файла (определяет по расширению). Сохраняет список уникальных слов. Имеет меню: вывести список на экран, продолжить с новыми данными или выйти. |
| `taskManager` | Проект в работе. Создан скелет, на недостающих функциях стоят заглушки. | 

В папке `uniqueWords` есть `main_test.go` — table-driven тесты с `t.Run` для clearData и sortingOfWords, покрывающие happy path и граничные случаи.


## Стек

- Go 1.25+
- Только стандартная библиотека (внешних зависимостей нет)

## Запуск / тесты

Папка — отдельный модуль. Запускать нужно изнутри папки:

```bash
cd uniqueWords
go run .
go test -v
```
